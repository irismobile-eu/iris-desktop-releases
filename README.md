# Iris Mobile Desktop — релізи

Тут лежать **тільки файли збірок** застосунку Iris Mobile Desktop для точок франшизи.
Вихідного коду тут немає — він у приватному репозиторії `irismobile-eu/iris-desktop`.

## Навіщо репозиторій публічний

Застосунок перевіряє оновлення через `electron-updater`, а той не вміє читати приватний
репозиторій без токена доступу. Зашивати токен у застосунок не можна — файл `app.asar`
розпаковується, і токен дістав би будь-хто. Тому артефакти лежать відкрито, а код —
закрито.

## Що в кожному релізі

| Файл | Навіщо |
| --- | --- |
| `Iris-Mobile-Desktop-<версія>-arm64.dmg` | Установка руками: відкрити, перетягнути в «Програми». |
| `Iris-Mobile-Desktop-<версія>-arm64-mac.zip` | Авто-оновлення. Squirrel.Mac не вміє ставити оновлення з DMG. |
| `latest-mac.yml` | Опис останньої версії: номер, хеші, розміри. Застосунок читає саме його. |
| `*.blockmap` | Часткове завантаження оновлення: качається лише те, що змінилося. |

Видаляти чи перейменовувати ці файли не можна — імена всередині `latest-mac.yml`
мають збігатися символ у символ, інакше оновлення знайдеться, завантажиться і мовчки
не встановиться.

## Вимоги

Mac на Apple Silicon, macOS 11 або новіша. Збірки підписані Developer ID і нотаризовані
Apple, тож відкриваються без попереджень Gatekeeper.
